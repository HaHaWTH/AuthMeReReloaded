**详细改动：**

1.  改进邮件发送逻辑，支持更多邮件
2.  关闭邮件发送（当服务器关闭时，向您发送邮件）
3.  原有漏洞修复
4.  反幽灵玩家（重复登录错误）
5.  按服务器分支使用最佳性能方法
6.  基岩兼容性（需要Floodgate）（基于 UUID）
7.  更新检查器
8.  集成 GUI 验证码功能（需要 Bedrock 兼容性和 ProtocolLib）（70% 异步）
9.  改进监听器
10. 改进玩家登录逻辑以减少延迟
11. 自动清除机器人数据
12. 支持**Folia（正在测试中）**
13. F键菜单兼容
14. 自动修复传送卡传送门/地底问题
15. **Velocity支持 (详见 [Velocity Support](./vc-support.md))**
16. 基岩版玩家自动登录（可配置）
17. 修复旧版本（MC 1.13-）中的 "潜影盒 "崩溃问题
18. 支持 **H2 数据库**
19. 虚拟线程支持
20. **100% 兼容原版 authme 和扩展**
21. 更多......
